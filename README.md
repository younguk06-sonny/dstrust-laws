# 부동산신탁 관계법령

신탁·정비사업·건축·민사 법령 30개를 매일 아침 법제처에서 자동으로 받아와,
폰·집 PC에서는 앱처럼, 회사 PC(인터넷 없음)에서는 HTML 파일 하나로 찾아보는 개인 법령집입니다.

## 쓰는 법
- **검색**: `신탁법 22조`, `도정법 시행령 47조`처럼 쓰고 엔터 → 그 조문으로 바로 이동. `관리처분계획`처럼 낱말만 쓰면 전체 법령에서 찾습니다. 약칭(자본시장법·도정법·건축물분양법·토지보상법 등)도 알아듣습니다.
- **조문 옆 버튼**: ☆ 즐겨찾기 · 복사(「법령명」 조문 형식) · 법제처 원문 열기(온라인일 때)
- **최근 개정** 탭: 자동 수집 중 시행 버전이 바뀐 법령이 날짜와 함께 쌓입니다.
- **폰에 설치**: 사이트를 연 뒤 브라우저 메뉴 → '홈 화면에 추가'. 한 번 열어두면 인터넷 없이도 열립니다.
- **회사 PC**: 오른쪽 위 '오프라인 파일' → `부동산신탁_관계법령_오프라인.html`을 USB 등으로 옮겨 더블클릭.

## 법령 목록 바꾸기
`laws.config.json`에 법령 정식 명칭을 넣거나 빼면, 저장하는 순간 자동 수집이 다시 돌아 반영됩니다.

## 자동 수집
- 매일 오전 6시 17분(한국시간) GitHub Actions가 `scripts/collect.mjs`를 실행합니다.
- 저장소 시크릿 `LAW_OC`(법제처 Open API 인증키)가 있으면 법제처 API로, 없으면 공개 법령 서버(korean-law-mcp, 공용 한도)로 받습니다.
- 시행 버전(MST)이 바뀐 법령만 다시 받습니다. 모두 다시 받으려면 Actions → '법령 자동 수집' → Run workflow에서 '처음부터 다시 받기'를 체크하세요.

자료 출처: 법제처 국가법령정보센터. 법적 효력이 필요한 판단은 원문을 꼭 확인하세요.
